One-Time Admin Account Setup

This page runs once to create the first OD Admin account. It talks directly to your Apps Script and Supabase project — nothing you type here is sent anywhere else. You can delete this file when you're done.

Check My Role (use this if the account was already created)

Signs in with the Email/Password above and checks your role — does NOT try to create the account again.

Connection Test (optional — does not touch your account)

Only use this if the button above showed an error. These two buttons send no password, no bootstrap key, and make no changes — they just check what your network allows.
